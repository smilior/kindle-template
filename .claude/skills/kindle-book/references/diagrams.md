# 概念図・対比図の描き方

書籍内の **図解**（対比・関係・フローなど）向け。製品 UI のスクショは `screenshots.md` を参照（再着色しない）。

## 原則

1. **色を増やさない** — 主役アクセントは1色だけ  
2. アクセントは **ポイント囲みと同じ緑**（`.callout-point` / `#2f9e5f`）  
3. 既存・副次・「ふつう側」は **グレー**  
4. 紙面に馴染むよう、背景は書籍地色に近いオフホワイト  

## パレット

| トークン | 値 | 使いどころ |
| --- | --- | --- |
| アクセント | `#2f9e5f` | 主役ヘッダー、主役枠、主役側の線・矢印・ドット |
| 緑（濃め文字） | `#247a48` | 緑地の上の強調ラベル（必要なときだけ） |
| 淡い緑地 | `#f0faf4` / `#f7fcf9` | 主役側の行・カードの薄い背景 |
| 緑の淡枠 | `#8fd0a8` | 小さなラベル枠 |
| グレー見出し | `#6e6a64` | 既存側・副次のヘッダー |
| グレー枠 | `#c8c4bc` | カード外枠 |
| グレー線 | `#8a8578` / `#b8b4ac` / `#d8d4cc` | 矢印・破線・区切り |
| 紙背景 | `#FFFEFA` | SVG 全体の地 |
| 墨 | `#3A3630` | タイトル・本文ノード |
| 補足文字 | `#5a5550` / `#6a6560` / `#8A8578` | サブラベル・注 |

**使わない（本書の概念図）:** オレンジ（旧主役色）、強いブルー、紫、赤などの多色役割分け。

## レイアウトの型

### 対比（1行1軸）

- 左: 既存・ふつう → グレー  
- 右: 本書の焦点 → 緑ヘッダー＋緑枠  
- 中央: 軸ラベル（薄いグレー帯＋白ピル）  
- 下の注記: 緑の **点線** 枠（ポイント囲みに近い）可  

見本: `book/images/os-compare.svg`

### 関係図

- ゾーン枠は薄いグレー  
- コア（エージェント等）: 淡い緑地＋緑枠  
- 重要ノード（門番等）: 緑ヘッダー可  
- 外部・副次: 白地＋グレー破線  
- 内部の流れ: グレー矢印／外へ・安全経路: 緑矢印  

見本: `book/images/ch1-roles.svg`

### 入口と二通り

- 共通の入口バー: 緑  
- 「あなた」側をわずかに緑枠、他はグレー  
- 二通りのカード: 副次＝グレーヘッダー、焦点＝緑ヘッダー  

見本: `book/images/ch1-env-share.svg`

## 書き出し

1. SVG を編集用の正本にする  
2. PNG は **幅 2x 以上**（例: viewBox 960 なら 1920px）  
3. `rsvg-convert` 等で書き出し後、**PNG を目視**（重なり・はみ出し・色トーン）  
4. 不備があれば SVG と PNG を両方直す  

## チェックリスト（図ごと）

- [ ] アクセントがポイント緑だけか  
- [ ] オレンジ／多色が残っていないか  
- [ ] 1行1軸（対比のとき）  
- [ ] 文字の重なり・線の貫通・はみ出しがないか  
- [ ] キャプションは HTML 側 `図: …`、図内タイトルと役割が被りすぎないか  

## やらないこと

- スクショ PNG を手動で塗り替える  
- ノードごとに別色を割り当てる（カテゴリ色のレインボー）  
- 細いゼブラだけに頼る（枠・帯で区切る）
