第1章 概要
1

これは何か

Cloudflare OS は、社内向けの AI 仕事場です。チャットに頼むと、答えだけでなく、スライドや小さな道具（Gadget）がその場に残ります。

従来のチャット AI では、良い回答も会話の中に閉じてしまいがちです。翌日には別の窓を開き、同僚への共有はコピー＆ペーストになります。この本が扱うのは、その「残らない」問題をどう短くするかです。

5 · はじめに

はじめに

この本は、Cloudflare OS を手元で動かしながら、「頼む → 形になる → 見て確定 → 渡す」を一度通すためのガイドです。

コードの深い解説はしません。画面を追い、同じ操作が再現できれば十分です。

  • 想定読者 — 非エンジニア寄り。ターミナルに抵抗がなければOK
  • 必要なもの — PC、Node.js、pnpm、AI プロバイダの API キー
  • 読み方 — 急ぎなら第2章→第4章→事例1から
