> 通常は「章を跨いで一気に全文を埋めない」運用だが、2026-09-21 にユーザーから「全てを対象に対応して」と明示指示があったため、全章を 1 回でまとめて起こした（AGENTS の例外扱い）。

| 箇所 | 変更 |
|------|------|

| 章末「この章で手元に残るもの」 | 各章の「この章のまとめ」☑ チェックリストに統合（同じ内容を箇条書き化） |
| サンプルID（#ch05-01 など） | 紙面からは省略。はじめにの案内文を「章番号から探す」に修正 |
| 節見出し | 1ページ1つに分割（元は同一ページに複数の小見出し） |
| 章末 | 「この章のまとめ」＋☑チェックリストを新設（元は `---` で終わり） |
| キーワード早見 | 章末（まとめ直前）に新設。付録A 用語集と食い違わせない |
| 箇条書き | リンクアイコンの行頭記号 → テンプレートの `.text-list` |
| ハルシネーションの注記 | 本文 → 用語囲み（callout） |
