# Kindle Layout Templates

B5（182×257mm）向けの書籍レイアウトテンプレート。  
文字なし空枠と、文言入り見本の2種。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 空枠テンプレート（12ページ） |
| `with-text.html` | 文字入り見本（同じ12ページ） |
| `templates.css` | 共通スタイル |
| `with-text.css` | 文字入り用の上書き |

## ページ一覧

1. 表紙  
2. 目次  
3. 本文  
4. 章扉  
5. はじめに  
6. おわりに  
7. 手順（1. 2. 3. ＋各項の下に画像）  
8. 図＋キャプション  
9. 囲み  
10. 表  
11. 章末まとめ  
12. 奥付  

## 使い方

1. `index.html` または `with-text.html` をブラウザで開く  
2. 上部の **印刷 / PDF** から PDF 化できる  

印刷時はブラウザの「背景のグラフィック」をオンにすると、塗りが安定します。

## デザインメモ

- 地色 `#FFFEFA` / 墨 `#3A3630` / 補足 `#8A8578` / 黄 `#F5E66A` / 囲み `#E8EEF6`
- h2: 下に黄線（幅いっぱい）
- h3: 下にグレー線（幅いっぱい）
- 左右余白 19mm（同値）
- 線は印刷でも消えにくいよう border 中心

## ライセンス

用途に合わせて設定してください。
