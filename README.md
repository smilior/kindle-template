# Kindle Layout Templates

B5（182×257mm）向けの書籍レイアウトテンプレートと、**対話しながら本を作るスキル**（`kindle-book`）を同梱したひな形リポジトリです。

## このリポジトリの使い方

**本リポジトリは「ひな形」です。** 直接編集して1冊を完成させる前提ではなく、**コピーして新規リポジトリを作り、その上で対話しながら書籍を作っていく**ための土台として使います。

### 想定フロー

1. このリポジトリを **テンプレートとしてコピー**（GitHub の *Use this template*、または fork / clone して別リポジトリ化）する  
2. 新規リポジトリを AI アシスタント（Claude Code / Cursor / Grok など）で開く  
3. **`kindle-book` スキル**で次の順に進める  
   1. **章題を一緒に考える**（タイトル・目次を対話で確定）  
   2. **その項目を一気に作成**（表紙・目次・各章のページ骨格を HTML に一括起こし）  
   3. **内容を詰める**（章ごと・見出しごとに本文や手順を磨く）  
4. 作業コピーの HTML をブラウザでプレビューし、**印刷 / PDF** で書き出す  

コピー先ごとに1冊（または1プロジェクト）を独立して管理し、このひな形リポジトリ本体は更新用の共通基盤として残します。

## スキル: kindle-book

場所: [`.claude/skills/kindle-book/`](.claude/skills/kindle-book/)

| パス | 内容 |
| --- | --- |
| `SKILL.md` | 対話フロー・ページ型・編集ルール |
| `assets/` | レイアウト原紙（HTML/CSS） |
| `references/page-types.md` | 空枠 ↔ 文字入りクラス対応表 |

### テンプレートファイル（assets）

| ファイル | 内容 |
| --- | --- |
| `index.html` | 空枠テンプレート（12ページ型） |
| `with-text.html` | 文字入り見本（同じページ型） |
| `templates.css` | 共通スタイル |
| `with-text.css` | 文字入り用の上書き |

作業時は `assets/` を **コピー**してから編集します（スキルの指示どおり）。原紙を直接完成原稿にしないでください。

## ページ型一覧

1. 表紙  
2. 目次  
3. 本文  
4. 章扉  
5. はじめに  
6. おわりに  
7. 手順（1. 2. 3. ＋各項の下に画像）  
8. 図＋キャプション  
9. 囲み  
10. 表  
11. 章末まとめ  
12. 奥付  

## プレビューと PDF 化

1. 作業中の `with-text.html` をブラウザで開く  
2. 上部の **印刷 / PDF** から PDF 化できる  

印刷時はブラウザの「背景のグラフィック」をオンにすると、塗りが安定します。

## デザインメモ

- 地色 `#FFFEFA` / 墨 `#3A3630` / 補足 `#8A8578` / 黄 `#F5E66A` / 囲み `#E8EEF6`
- h2: 下に黄線（幅いっぱい）
- h3: 下にグレー線（幅いっぱい）
- 左右余白 19mm（同値）
- 線は印刷でも消えにくいよう border 中心

## ライセンス

用途に合わせて設定してください。
