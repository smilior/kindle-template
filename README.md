# Kindle Layout Templates

B5（182×257mm）向けの書籍レイアウトテンプレート。  
文字なし空枠と、文言入り見本の2種。

## このリポジトリの使い方

**本リポジトリは「ひな形」です。** 直接編集して1冊を完成させる前提ではなく、**コピーして新規リポジトリを作り、その上で対話しながら書籍を作っていく**ための土台として使います。

### 想定フロー

1. このリポジトリを **テンプレートとしてコピー**（GitHub の *Use this template*、または fork / clone して別リポジトリ化）する  
2. 新規リポジトリを AI アシスタント（Claude / Cursor など）で開く  
3. **対話しながら** テーマ・構成・本文・レイアウトを詰めていく  
4. レイアウト HTML（`index.html` / `with-text.html`）をベースに、ページ構成や文言を書籍向けに整える  
5. ブラウザでプレビューし、**印刷 / PDF** で書き出す  

対話の中で決まっていく想定の例:

- 書籍タイトル・ターゲット読者・ジャンル  
- 章立て・ページ構成（表紙・目次・本文・手順・図表など）  
- 本文の下書きと推敲  
- レイアウト枠への文言・画像の当て込み  

コピー先ごとに1冊（または1プロジェクト）を独立して管理し、このひな形リポジトリ本体は更新用の共通基盤として残します。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 空枠テンプレート（12ページ） |
| `with-text.html` | 文字入り見本（同じ12ページ） |
| `templates.css` | 共通スタイル |
| `with-text.css` | 文字入り用の上書き |

## ページ一覧

1. 表紙  
2. 目次  
3. 本文  
4. 章扉  
5. はじめに  
6. おわりに  
7. 手順（1. 2. 3. ＋各項の下に画像）  
8. 図＋キャプション  
9. 囲み  
10. 表  
11. 章末まとめ  
12. 奥付  

## プレビューと PDF 化

1. `index.html` または `with-text.html` をブラウザで開く  
2. 上部の **印刷 / PDF** から PDF 化できる  

印刷時はブラウザの「背景のグラフィック」をオンにすると、塗りが安定します。

## デザインメモ

- 地色 `#FFFEFA` / 墨 `#3A3630` / 補足 `#8A8578` / 黄 `#F5E66A` / 囲み `#E8EEF6`
- h2: 下に黄線（幅いっぱい）
- h3: 下にグレー線（幅いっぱい）
- 左右余白 19mm（同値）
- 線は印刷でも消えにくいよう border 中心
