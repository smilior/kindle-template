# Kindle Layout Templates

B5（182×257mm）向けの書籍レイアウトテンプレートと、対話しながら本を作るスキル（`kindle-book`）を同梱したひな形リポジトリです。

**使い方（HTML 手順書 / GitHub Pages）:**  
https://smilior.github.io/kindle-template/

---

## 使い方マニュアル

### 1. このリポジトリの位置づけ

| もの | 役割 |
| --- | --- |
| このリポジトリ（ひな形） | スキルとレイアウト原紙の共通基盤。1冊の完成原稿置き場にはしない |
| コピーした新規リポジトリ | **1冊（または1プロジェクト）用**の作業場。ここで対話して本を作る |

ひな形を直接いじって1冊完成させる想定ではありません。**必ずコピーしてから**使います。

### 2. 事前準備

1. GitHub でこのリポジトリを開く  
2. **Use this template**（または fork / clone して別リポジトリ化）でコピーする  
3. コピー先をローカルに clone する  
4. Claude Code / Cursor / Grok など、スキルを読める AI でプロジェクトを開く  

コピー先に `.claude/skills/kindle-book/` が入っていることを確認してください。

### 3. 制作の3ステップ（必ずこの順）

```
章題を一緒に考える  →  項目を一気に作成  →  内容を詰める  →  PDF
```

本文の長文を最初から書かないのがポイントです。章立てが固まってから箱を立て、そのあと中身を磨きます。

| ステップ | やること | まだやらないこと |
| --- | --- | --- |
| **① 章題** | 書名・想定読者・章タイトルを対話で確定 | HTML 一括生成、長文の本文 |
| **② 一気に作成** | 表紙・目次・各章扉・本文の枠などを HTML に一括起こし | 全章の完成原稿 |
| **③ 内容を詰める** | 章ごと・見出しごとに本文・手順・図・囲みを書く | 章題を大きく組み替える（必要なら①に戻る） |

### 4. AI への話し方（例）

スキル名を出さなくても、「Kindle本を作りたい」「章立てから」などで `kindle-book` が使われる想定です。迷ったら次のように依頼してください。

**最初（章題）**

```
Kindle本を作りたい。テーマは「〇〇」。
まだ章立ては決まっていないので、章題から一緒に考えて。
```

**章題が固まったあと（骨格を一気に）**

```
この目次で確定。テンプレートに沿って骨格を一気にHTMLにして。
（目次を貼る）
```

**肉付け**

```
第2章の中身を詰めて。手順ページと囲みも使って。
```

**途中再開**

```
骨格まではできている。第3章から続きを書いて。
```

### 5. 作業ファイルの置き方

スキル内の `assets/` は **原紙**です。完成原稿として直接編集しません。初回はコピーしてから編集します。

```bash
# プロジェクト直下に book/ を作る例
mkdir -p book
cp .claude/skills/kindle-book/assets/* book/
```

| ファイル | 役割 |
| --- | --- |
| `book/with-text.html` | **主成果物**（文字入りの本） |
| `book/templates.css` | 共通スタイル |
| `book/with-text.css` | 文字入り用スタイル |
| `book/index.html` | 空枠の参照用（任意） |

編集の中心は常に **`with-text.html`** です。

### 6. プレビューと PDF 化

1. `with-text.html` をブラウザで開く  
2. 画面上部の **印刷 / PDF** をクリック（またはブラウザの印刷）  
3. 用紙は B5 相当・余白はブラウザ側で「既定」寄りでよい  
4. **背景のグラフィック**（背景色の印刷）を **オン** にする  
5. PDF に保存する  

印刷時だけ出るツールバー（ページジャンプなど）は印刷対象外（`no-print`）です。

### 7. ページ型（何が用意されているか）

全部を1冊に使う必要はありません。本の種類に合わせて選びます。

| # | 型 | 用途の例 |
| --- | --- | --- |
| 1 | 表紙 | 書名・サブタイトル |
| 2 | 目次 | 章一覧 |
| 3 | 本文 | 見出し＋段落＋任意で図 |
| 4 | 章扉 | 章番号と章題だけ |
| 5 | はじめに | 導入・想定読者 |
| 6 | おわりに | まとめ・次の一歩 |
| 7 | 手順 | 1. 2. 3. と各項の下の図 |
| 8 | 図＋キャプション | 図中心のページ |
| 9 | 囲み | ポイント / 注意 / 用語 |
| 10 | 表 | 用語集・比較など |
| 11 | 章末まとめ | できたこと・次章への橋 |
| 12 | 奥付 | 書名・版・注記 |

典型の並び:

`表紙 → 目次 → はじめに →（章扉 → 本文… → 章末まとめ）× N → おわりに → 奥付`

### 8. よくある進め方の注意

- **章題が未確定のまま全文を書かない** — 手戻りが一番大きい  
- **原紙（`assets/`）を完成原稿にしない** — 必ず作業コピーを使う  
- **肉付けは章単位** — 「全部一気に完成原稿」より、1章ずつ確認した方が安全  
- **画像は後から** — 仮の差し込み枠（プレースホルダ）を置いて先に文章を固めてよい  
- **ページ番号** — 骨格段階は仮でよい。仕上げで目次と通し番号を合わせる  

### 9. リポジトリ構成

```
kindle-template/   # ひな形（またはコピー先）
├── README.md                 # このマニュアル
├── .gitignore
└── .claude/skills/kindle-book/
    ├── SKILL.md              # AI 向け手順（対話ルールの正本）
    ├── assets/               # レイアウト原紙（HTML/CSS）
    ├── references/
    │   └── page-types.md     # 空枠と文字入りクラスの対応
    └── evals/                # スキル評価用サンプル（書籍データではない）
```

詳細なマークアップや AI の振る舞いの正本は [`.claude/skills/kindle-book/SKILL.md`](.claude/skills/kindle-book/SKILL.md) を参照してください。

## デザインメモ

- サイズ: B5 182×257mm / 左右余白 19mm  
- 色: 地 `#FFFEFA` / 墨 `#3A3630` / 補足 `#8A8578` / 黄 `#F5E66A` / 囲み `#E8EEF6`  
- 見出し: h2 は下に黄線、h3 は下にグレー線  
- 線は印刷でも消えにくいよう border 中心
