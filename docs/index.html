Kindle Template 使い方

B5 レイアウトをコピーし、AI と対話しながら1冊を作るひな形です。

1. 前提

  • このリポジトリはひな形。直接1冊を完成させない
  • コピーした新規リポジトリで作業する

2. 準備

  1. GitHub で Use this template（または fork / clone）
  2. ローカルに clone し、AI（Claude / Cursor / Grok など）で開く
  3. .claude/skills/kindle-book/ があることを確認

3. 制作の順（必須）

① 章題を決める → ② 骨格を一気に → ③ 内容を詰める → PDF
ステップやることやらないこと
① 章題 書名・章タイトルを対話で確定 長文・HTML一括完成
② 骨格 表紙・目次・各章の枠を HTML に一括 全章の完成原稿
③ 肉付け 章ごと・見出しごとに本文を書く 章題の大幅な組み替え

章題が固まってから箱を立て、そのあと中身を磨く。

4. AI への例

# 最初
Kindle本を作りたい。テーマは「〇〇」。
章題から一緒に考えて。

# 章題確定後
この目次で確定。骨格を一気にHTMLにして。

# 肉付け
第2章の中身を詰めて。手順と囲みも使って。

    3. 「背景のグラフィック」をオン
    4. PDF 保存
