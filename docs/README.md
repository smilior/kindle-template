## 書籍の出版資料は？

KDP 入力値や表紙デザイン依頼書は、**本ごと**に置きます。見本は次の場所にあります。

```bash
open examples/cloudflare-os/docs/JP/kdp-metadata.html   # Amazon.co.jp
open examples/cloudflare-os/docs/EN/kdp-metadata.html   # Amazon.com
open examples/cloudflare-os/JP/with-text.html           # 本文（見本）
```

自分の本を作るときは `book/docs/JP/` に同じ形で用意してください。
