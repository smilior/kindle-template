Description

Book description

Shown on Amazon. Keep under 4,000 characters.

Ask once, keep the tool — a hands-on intro that walks you through the screens.

Cloudflare OS is a browser environment where you chat with generative AI (an agent), build slides and small apps on the spot, and keep using them. This book is for readers closer to non-engineers who want to fix small daily frictions themselves, not for people chasing deep programming theory.

It is not about replacing company core systems. While internal IT cannot always keep up, people still need tiny tools every day. You will build those small apps in natural language and connect them safely through Gatekeepers to services like GitHub — by doing, not only reading.

What you will learn
• The big picture and terms (agent / Gadget / Blueprint / Gatekeepers)
• Local setup and how to read the UI
• The loop: ask → Accept → follow-up until it fits
• Hands-on: customer slides, a weekly task board, a GitHub Issue dashboard
• Connect outside services only as far as you need

In real work, make → look → fix beats one perfect prompt. Start small and aim at the gaps on your own desk.

This is an unofficial learning guide. Cloudflare OS is in Early Access; screens and behavior may change.
