## 4. ビジュアルの方向性

### 推奨する雰囲気

- 明るい・紙の本のような落ち着き（地色はオフホワイト〜ごく薄いグレー可）  
- アクセントは**緑**（本文のポイント色に近い `#2f9e5f` 前後）  
- 情報は少なく、**サムネでも書名が読める**太さ・コントラスト  

### 構図の案（いずれか、または組み合わせ）

| 案 | イメージ | 意図 |
|----|----------|------|
| A. 文字中心 | 余白多め。書名を大きく。図は最小 | 信頼・入門書らしさ |
| B. チャット＋成果 | 吹き出しや入力欄の抽象形 ＋ できた「小さなカード／ウィンドウ」1枚 | 「頼む → 残る」 |
| C. 接続の抽象 | 小さなノードや鍵を控えめに。大規模配線図は不可 | 「安全につなぐ」 |

**避けたいビジュアル**

- コードの壁・ターミナル全面  
- ロボット・脳・ネオンの「AI っぽい」ストック感  
- オレンジや多色の派手なダッシュボード全面  
- Cloudflare 公式ブランドの模倣（ロゴの無断使用・公式サイトのコピー）  

### レイアウトの目安（上から）

```
［余白］

        Cloudflare OS 入門          ← 最大・最も読む
        ────────（細いアクセント線可）
        小さなアプリを、安全につなぎながら作る
        頼むだけで、仕事の道具が手元に残る。
        smilior.com
        中川 将広

［余白 または 下部に小さな図1点］
```

- 著者ブロックは**中央揃え**  
- キャッチ・著者の色は、サブタイトルより一段弱い色（グレー系）でも可  
- 書名・サブは本文色（ダークグレー〜墨）でコントラストを確保

## 5. サイズ・技術仕様

| 用途 | サイズ目安 | 備考 |
|------|------------|------|
| Kindle 表紙 | **1600×2560 px** 前後（縦長 1:1.6 程度） | Amazon 推奨に近い比率。最終はストア規定で調整可 |
| 印刷 B5 表紙 | **182×257 mm**（塗り足し +3 mm 推奨） | 本文レイアウトが B5 |
| 解像度 | 印刷 300 dpi 相当 / 画面用は 2x 可 | |
| セーフエリア | 端 5〜8% に重要文字を置かない | Kindle クロップ対策 |
| カラー | sRGB（Kindle）／印刷時は CMYK 変換前提で RGB 入稿でも可（要確認） | |

**納品ファイル名の例**

- `cover-kindle-v1.png`  
- `cover-b5-print-v1.pdf`  
- `cover-source.fig`（または該当ソフトの編集データ）

## 7. 評価の観点（受け入れ条件）

次を満たす案を採用候補とします。

1. サムネサイズでも **「Cloudflare OS 入門」** が読める  
2. サブタイトルから **小さなアプリ** と **安全** が伝わる  
3. 非エンジニアが「自分向けかも」と感じる（技術書の威圧感が弱い）  
4. 公式製品の宣伝物と誤認されない  
5. 必須の文字4点が欠けていない・誤字がない
