内容紹介（商品説明）

頼むだけで、仕事の道具が手元に残る——そんな働き方の入口を、画面操作中心に解説する入門書です。

Cloudflare OS は、ブラウザ上で生成AI（エージェント）に話しかけ、スライドや小さなアプリをその場で作り、そのまま使える環境です。本書の対象は、プログラミングの深い知識よりも「ちょっとした不便」を自分で解消したい非エンジニア寄りの読者です。

全社の基幹システムを置き換える話ではありません。社内SEがなかなか手が回らない一方で、現場では毎日困る——そんな小さなアプリを、自然言語で作り、Gatekeepers 経由で GitHub などと安全につなぐ流れを、手を動かしながら通します。

【この本でわかること】
・Cloudflare OS の全体像と用語（エージェント / Gadget / Blueprint / Gatekeepers）
・ローカル環境の用意と画面の見方
・依頼 → Accept → 追依頼で仕上げる基本のループ
・実践：顧客向けスライド、週次タスク看板、GitHub Issue ダッシュボード
・外のサービスへは「必要なものだけ」つなぐ考え方

完璧な一文より、作って・見て・直す繰り返しが現場では役立ちます。まずは小さく始めて、手元のすき間業務に当ててみてください。
